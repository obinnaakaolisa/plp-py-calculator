# Basic Python Calculator Program

A simple command-line calculator built with Python that performs basic arithmetic operations.

## Description

This program allows users to perform basic mathematical operations (addition, subtraction, multiplication, and division) on two numbers. It includes input validation and error handling for division by zero.

## Features

- ✅ Addition (+)
- ✅ Subtraction (-)
- ✅ Multiplication (*)
- ✅ Division (/)
- ✅ Error handling for division by zero
- ✅ Input validation for operations
- ✅ Supports decimal numbers

## Requirements

- Python 3.x

## How to Run

1. Make sure you have Python installed on your computer
2. Download or clone this repository
3. Open your terminal/command prompt
4. Navigate to the program directory
5. Run the program:
   ```bash
   python calculator.py
   ```

## Usage Example

```
Enter the first number: 10
Enter the second number: 5
Enter the operation (+, -, *, /): +
10.0 + 5.0 = 15.0
```

## Sample Operations

| Operation | Input Example | Output |
|-----------|---------------|--------|
| Addition | 10 + 5 | 15.0 |
| Subtraction | 10 - 5 | 5.0 |
| Multiplication | 10 * 5 | 50.0 |
| Division | 10 / 5 | 2.0 |

## Error Handling

The program handles the following errors:
- **Division by zero**: Displays an error message when attempting to divide by zero
- **Invalid operation**: Alerts the user if an operation other than +, -, *, or / is entered
